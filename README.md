# Лендинг репетитора

Современный одностраничный сайт для репетитора по русскому языку, английскому языку и биологии.

## Технологии

- React 19 + Vite
- React Router
- Framer Motion
- Lucide React
- CSS Modules

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:5173`

## Сборка

```bash
npm run build
npm run preview
```

## Структура проекта

```
src/
├── assets/images/     # Фотографии (замените на свои)
├── components/
│   ├── layout/        # Header, Footer
│   ├── sections/      # Секции лендинга
│   └── ui/            # Переиспользуемые UI-компоненты
├── data/
│   ├── content.js     # Все тексты сайта — редактируйте здесь
│   └── images.js      # Импорты изображений
└── styles/
    ├── global.css     # Глобальные стили
    └── variables.css  # CSS-переменные (цвета, шрифты)
```

## Как редактировать

### Тексты
Все тексты вынесены в `src/data/content.js` — имя, контакты, отзывы, FAQ и т.д.

### Фотографии
Замените файлы в `src/assets/images/`:

| Файл | Назначение |
|------|-----------|
| `teacher.jpg` | Hero — фото преподавателя |
| `about.jpg` | Секция «О преподавателе» |
| `gallery-1.jpg` … `gallery-6.jpg` | Галерея занятий |
| `cert-1.jpg` … `cert-4.jpg` | Дипломы и сертификаты |
| `student-1.jpg` … `student-4.jpg` | Аватары в отзывах |

### Цвета и стили
CSS-переменные в `src/styles/variables.css`

## Секции сайта

1. Hero — главный экран со статистикой
2. О преподавателе
3. Предметы (русский, английский, биология)
4. Преимущества
5. Дипломы и сертификаты (с lightbox)
6. Галерея занятий
7. Отзывы (слайдер)
8. Формат занятий
9. FAQ (аккордеон)
10. Контакты и форма записи
11. Footer
